# Energy Studies

Open **Scenes/Energy Studies.unity** and press Play to compare the four presets in motion. Trip Laser is narrow and steady; Mining Plasma has a luminous outer sheath; Golden Tether bends and trails a moving target; Tractor Stream sends bands back towards its source.

Use the prefabs independently. Assign the endpoint provider to the target you want to follow and adjust the renderer width for your world scale. The tether and tractor effects are visual only: neither changes health, applies force, nor takes ownership of its target.

## Sample presentation

On import, choose **Install** to use the shared fonts, icons, and sample header. To install later, choose **Tools > jlinkdev > Beams > Install Sample Framework**. Before the release tag is published, use Package Manager's **Install package from disk** and select `Packages/com.jlinkdev.sample-framework/package.json` from a Unity Utilities checkout.
