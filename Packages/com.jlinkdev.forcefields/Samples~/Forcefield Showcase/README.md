# Forcefield Showcase

Open `Scenes/Forcefield Showcase.unity` and enter Play mode. The saved hierarchy contains the preset gallery, stress wall, lights, camera, and refractive cores. Expand either group to edit an individual shield.

- Click any field to add a precise impact.
- Toggle automatic impacts to observe continuous ring-buffer reuse.
- Cycle presets to see runtime blending.
- Open the stress wall to render twenty independent fields.

The Showcase Camera requests opaque and depth textures for refraction and intersections.

## Sample presentation

On import, choose **Install** to use the shared fonts, icons, and sample header. To install later, choose **Tools > jlinkdev > Forcefields > Install Sample Framework**. Before the release tag is published, use Package Manager's **Install package from disk** and select `Packages/com.jlinkdev.sample-framework/package.json` from a Unity Utilities checkout.
