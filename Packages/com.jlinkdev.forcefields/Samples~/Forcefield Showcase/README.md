# Forcefield Showcase

Open `Scenes/Forcefield Showcase.unity` and enter Play mode. The scene builds an interactive preset gallery using the supplied material and preset assets.

- Click any field to add a precise impact.
- Toggle automatic impacts to observe continuous ring-buffer reuse.
- Cycle presets to see runtime blending.
- Open the stress wall to render twenty independent fields.

For the full visual result, enable **Opaque Texture** and **Depth Texture** on the active URP asset. The sample remains usable when either is disabled.
