# Changelog

All notable changes to this package are documented here.

## [0.1.0] - 2026-08-11

### Added

- URP forcefield shader with Fresnel energy, procedural noise and hex patterns, screen-space refraction, chromatic splitting, and depth intersections.
- Allocation-free 4/8/16/32-slot impact ring buffer with spherical and generic propagation modes.
- Reusable forcefield presets, runtime intensity, preset blending, compound renderer support, and impact events.
- Optional collision-to-impact adapter.
- Custom inspectors, diagnostics, creation menus, showcase sample, documentation, and automated tests.
