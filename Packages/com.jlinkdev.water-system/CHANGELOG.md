# Changelog

## 0.1.0 - Unreleased

- Added finite rectangular water bodies with shared CPU/GPU wave parameters and
  triangle-interpolated surface queries.
- Added URP surface shading, displaced waterline boundary rendering, underwater
  absorption, fog, saturation, distortion, and procedural caustics.
- Added camera state and contact events, debug views, and point-based buoyancy.
- Added an optional suspended-particle cloud clipped to the animated finite volume.
- Added explicit renderer setup, three profile presets, inspector guidance, and
  the self-contained Water Laboratory sample.
- Defined initial supported scope and a validation record for release readiness.
