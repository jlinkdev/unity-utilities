# Changelog

All notable changes to this package are documented here.

## [1.0.0-pre.1] - 2026-08-11

### Added

- Composable transform, raycast, sphere-cast, and smoothed endpoint providers with surface metadata.
- Straight and Bezier path providers plus resampling, sag, structural noise, electrical, and branch modifiers.
- Neutral contact enter/stay/exit/tick events and non-allocating caller-owned polling.
- Procedural ribbon renderer, Line Renderer adapter, renderer groups, render profiles, endpoint visuals, and pulse driver.
- Animated URP beam shader, four material presets, a Shader Graph-compatible function library, and four native beam subgraphs.
- Editor creation menus, live diagnostics, importable demo, documentation, and automated EditMode coverage.
