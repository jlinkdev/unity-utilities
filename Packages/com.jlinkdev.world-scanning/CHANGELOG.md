# Changelog

All notable changes to this package are documented here.

## [0.1.0] - 2026-08-11

### Added

- Allocation-free runtime scan system with stable handles and 16 concurrent pulses.
- Spherical and cylindrical profiles with animated radius, intensity, and color.
- URP Render Graph renderer feature with bands, trails, triplanar grids, edge accents, noise, and distance fading.
- Scan-aware HLSL functions and a reference reveal Lit shader.
- Gameplay receivers, component and system events, cancellation, and live intensity control.
- Timeline track and scan clip.
- Setup utilities, custom inspectors, scene gizmos, and EditMode coverage.
- Professional greybox demo sample and package documentation.
